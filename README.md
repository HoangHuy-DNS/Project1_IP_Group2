# ỨNG DỤNG KHÔI PHỤC ẢNH CŨ

## 1. Giới thiệu

Đây là đồ án môn Xử lý ảnh với chủ đề:

**Ứng dụng khôi phục ảnh cũ**

Mục tiêu của dự án là xây dựng một ứng dụng có giao diện đồ họa cho phép người dùng mở ảnh, áp dụng các phương pháp xử lý để khôi phục ảnh và lưu kết quả.
